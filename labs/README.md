# Original coursework labs

These five scripts are preserved unchanged from the local BCI learning workspace. They provide the starting point for the portfolio; use `../run_demo.py` for the self-contained, reproducible experiment.

`lab2.py` expects a local `eeg_recording_raw.csv`, which is intentionally not distributed. `lab3.py`, `lab4.py`, and `lab5.py` execute work at import time and depend on one another. Several scripts open interactive figures; `lab5.py` also writes a model file. They are historical learning examples and are not the supported demo entry point.

The original lab code is associated with the Udemy course **Mastering Brain-Computer Interfaces & Neurotechnology**. See the portfolio report for a review of its methodological limitations.
